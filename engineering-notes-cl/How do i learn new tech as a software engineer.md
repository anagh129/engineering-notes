# How do i learn new tech as a software engineer

> Source: `How do i learn new tech as a software engineer.txt` · Transcript 16 of 43

## 📝 Description
A rambly, unstructured talk on **how the host learns new technology**, prompted by a viewer asking where he finds all this information.

## ⚠️ Problem
There is too much new technology to keep up with, and many engineers learn only when a job forces them to (reactively).

## ✅ Solution
Be proactive and curious: follow good sources, pick up topics from news and community questions, and **break each technology down to its fundamentals**.

## 🔍 Explanation
1. **Early career:** he began professionally in 2004 and solved whatever problem was in front of him with whatever tool was needed (reactive).
2. **Shift:** later, he started asking why tools exist and how they work.
3. **Sources:** people on Twitter, tech news, and questions from viewers.
4. **Example:** hearing about **IPFS** (content is duplicated across a set of machines, not truly distributed) sparked curiosity. He read about it, made a video and learned more because viewers pushed him.
5. **Method:** break a new technology into first principles. Once you understand how it works it stops feeling like magic.

## 🤖 Claude's Notes
- A practical loop: **hear → read overview → find the problem it solves → build a tiny demo → explain it to someone**.
- Teaching (blog, video, notes) is itself a strong learning technique.

## 🎯 Key Takeaways
- Learn proactively, not only when forced.
- Reduce new tech to fundamentals and the problem it solves.
- Use your community as a source of topics.
